🔹 Como baixar via PowerShell (alternativa)

Caso o botão acima não funcione, você pode usar o seguinte comando no PowerShell, lembrando que o arquivo deve estar no mesmo diretório em que o PowerShell está sendo executado:

Copy-Item .\BDSIA202606b.exe -Destination "$env:USERPROFILE\Downloads\BDSIA202606b.exe"

Ou, se preferir usar Invoke-WebRequest apontando para o endereço local:

Invoke-WebRequest -Uri "http://localhost/pasta_do_site/BDSIA202606b.exe" -OutFile "$env:USERPROFILE\Downloads\BDSIA202606b.exe"

🔹 Sobre o BDSIA

O BDSIA (Base de Dados do Sistema de Informações Ambulatoriais) é o arquivo de instalação/atualização do sistema que consolida os dados dos procedimentos ambulatoriais realizados no SUS. A versão disponibilizada (202606b) contém as atualizações referentes à competência Junho de 2026.

Mantenha seu sistema sempre atualizado para garantir a correta transmissão dos dados ao DATASUS.
